# EPR System

A lightweight ERP app for managing products, stock, sales, receipts, and staff.

The project source is expanded into the repository root by the **Expand EPR System source** GitHub Action from the uploaded source archive.

- Node.js: 26.13.0
- Framework: Next.js 16
- Backend: Supabase
- Main application: stock, sales, receipts, staff management, EN/FR language toggle

The app uses these browser-safe Vercel variables:

- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY

Never commit a Supabase secret key or service-role key.
